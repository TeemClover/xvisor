# ชุดสกิล X-VISOR

ทำคลิปแรกของพี่ด้วย Claude ไม่ต้องติดตั้งอะไร ไม่ต้องออกกล้อง
ได้บทพูด ลำดับช็อต ข้อความบนจอ และแคปชัน จากรูปหรือวิดีโอที่มีอยู่ในมือถือ

เว็บแนะนำและบทเรียน: https://www.myclover.com/xvisor/

## เริ่มเลย (3 ขั้น)

**1. คัดลอกข้อความนี้**

```
พี่เป็น X-VISOR มือใหม่ ช่วยพี่ทำคลิปแรกจากชุดความรู้นี้ https://github.com/TeemClover/xvisor ถ้าเปิดอ่านได้ ให้อ่านไฟล์ START-HERE.md แล้วใช้คู่มือและข้อมูลที่อนุมัติแล้วในนั้น ถามพี่ทีละเรื่องเฉพาะที่จำเป็น พี่ตอบ ก ข ค หรือ ง พิมพ์เองได้ ถ้าเปิดอ่านไม่ได้ บอกพี่สั้น ๆ ว่าต้องแนบไฟล์ไหน
```

**2. เปิด Claude แล้ววางในแชตใหม่**

**3. ตอบ ก ข ค หรือ ง** (ง คือพิมพ์เอง) แนบรูปหรือวิดีโอที่มีได้เลย

ถ้าอยากเริ่มด้วยโจทย์จริง เพิ่มต่อท้ายข้อความได้ เช่น "พี่มีรูปเครื่องชั่งที่ถ่ายไว้เมื่อเช้า ไม่อยากออกกล้อง"

## ถ้า Claude เปิดลิงก์ไม่ได้

บางแอปหรือบางบัญชีเปิดลิงก์ GitHub ไม่ได้ ใช้วิธีนี้แทน:
1. เปิดไฟล์ [X-VISOR-START.md](https://raw.githubusercontent.com/TeemClover/xvisor/main/X-VISOR-START.md) แล้วบันทึกไฟล์ หรือคัดลอกเนื้อหาทั้งหมด
2. แนบไฟล์ (หรือวางเนื้อหา) ในแชต Claude แล้วพิมพ์ว่า "ช่วยพี่ทำคลิปแรกจากไฟล์นี้"

ไฟล์เดียวนี้มีทุกอย่างที่ต้องใช้ทำคลิปแรก ไม่ต้องเปิดลิงก์อื่น

## ติดตั้งไว้ใช้ซ้ำ (ไม่ต้องวางข้อความทุกครั้ง)

ทำครั้งเดียว บน Claude เว็บหรือแอปคอมพิวเตอร์:
1. ดาวน์โหลด [xvisor-skill.zip](https://raw.githubusercontent.com/TeemClover/xvisor/main/downloads/xvisor-skill.zip)
2. เปิด Claude ไปที่ Customize > Skills แล้วอัปโหลดไฟล์ zip
3. เปิดสวิตช์สกิล X-VISOR ไว้ (ต้องเปิด Code execution and file creation ในการตั้งค่าก่อน)
4. ตรวจว่าสำเร็จ: เริ่มแชตใหม่แล้วพิมพ์ "ช่วยพี่ทำคลิปแรก" ถ้า Claude ถามแบบ ก ข ค ง ตามคู่มือนี้โดยไม่ต้องวางข้อความเริ่มงาน แปลว่าใช้สกิลอยู่

ขั้นตอนอ้างอิงจากเอกสารทางการของ Claude: https://support.claude.com/en/articles/12512180-using-skills-in-claude
ไม่เห็นเมนู Skills ให้ใช้วิธีวางข้อความข้างบนต่อไป ได้ผลเหมือนกันแค่ต้องวางทุกครั้งที่เริ่มแชตใหม่

ผู้ใช้ Claude Code: คัดลอกโฟลเดอร์ `skills/xvisor` ไปไว้ที่ `~/.claude/skills/xvisor`

## สิ่งที่ทำได้

| อยากทำอะไร | ได้อะไร |
|---|---|
| ทำคลิป | ชุดพร้อมถ่าย: Hook บท ช็อต ข้อความบนจอ แคปชัน พร้อมตรวจคำเสี่ยง |
| วางแผนช่อง | แผน 1 หน้า และตารางสัปดาห์แรก |
| หาข้อมูลสินค้า | ข้อมูลสินค้า CloverX ฉบับสรุป พร้อมลิงก์หน้าทางการให้ตรวจ |
| หาโลโก้และภาพ | โลโก้ XIRCLE, HabiX, RoutineX และภาพสินค้า ลิงก์ตรงให้โหลด |
| ฝึกใช้ AI | บทเรียนสั้น 3 บท จบแล้วมีชิ้นงาน |

## ที่ยังไม่มีในชุดนี้
- วิดีโอสอนใช้ Claude (ทีมกำลังเตรียม)
- โลโก้ CloverX และ MaxAge ฉบับไฟล์ต้นฉบับ
- ภาพหน้าจอแอปที่ได้รับอนุญาตให้เผยแพร่
- ตัวตัดต่อวิดีโอบนเครื่องคอมพิวเตอร์

## ข้อควรรู้
- ข้อมูลสินค้าสรุปจากหน้าเว็บสาธารณะ ณ วันที่ในไฟล์ [version.md](skills/xvisor/references/version.md) ก่อนโพสต์ ตรวจราคา โปรโมชัน ฉลาก และคำเตือนกับหน้าทางการทุกครั้ง
- คู่มือตรวจคำเป็นแนวทางลดความเสี่ยง ไม่ใช่การรับรองทางกฎหมาย
- AI อาจผิดพลาดได้ อ่านงานก่อนโพสต์เสมอ ห้ามส่งข้อมูลสุขภาพหรือรูปของลูกค้าให้ AI โดยไม่ได้รับอนุญาต

## สำหรับผู้ดูแล repo
```
python3 scripts/build.py   # สร้างไฟล์ที่สร้างอัตโนมัติ (X-VISOR-START.md, zip, version.md)
python3 scripts/check.py   # ตรวจก่อน push (เพิ่ม --online เพื่อเปิดทุกลิงก์)
```
แก้ที่ `skills/xvisor/` และ `manifest.json` เท่านั้น ห้ามแก้ไฟล์ที่สร้างอัตโนมัติด้วยมือ ข้อความเริ่มงานอยู่ที่ `manifest.json` ที่เดียว และเว็บ myClover ใช้ข้อความเดียวกัน

เนื้อหาและภาพเป็นของ CloverX และผู้เกี่ยวข้อง ใช้เพื่อทำสื่อในบทบาท X-VISOR ตามที่บริษัทอนุญาต ดู [NOTICE.md](NOTICE.md)
