# DK-05 รีวิวลูกค้า → คลิปสั้นโทน HabiX

เทปรีวิวลูกค้าหนึ่งคน (หนึ่งหรือหลายไฟล์) เข้า → คลิปสั้นแนวตั้งหลายตอน ออก
หน้าตาต้องตรงกับภาพอ้างอิงใน `references/look/` ทุกครั้ง (อ่าน `references/look/README.md` ก่อนเริ่ม) สูตรละเอียดของแต่ละส่วน: `references/dk05-recipe.md`

`<skill>` ด้านล่างคือโฟลเดอร์นี้ ทุกคำสั่งรันในโฟลเดอร์โปรเจ็กต์ของงาน (โฟลเดอร์ที่มี `project.json`) ผ่าน `<skill>/kit/rv`

## หน้าตาของ DK-05 (ห้ามเปลี่ยนเอง)

1. **สีไฮไลต์** เขียว HabiX `#3FA834` ในหัวเรื่อง ซับ และฉากปิด (คลิป Xircle เปลี่ยนเป็นฟ้า `#4285F4` เองทุกจุด)
2. **ป้ายชื่อ** การ์ดพื้นครีม มุมมน ตัวอักษรเขียวเข้ม โลโก้ HabiX มุมขวาบน คลื่นเขียวมุมขวาล่าง 3 บรรทัด ชื่อ / อายุ / อาชีพ จาก `PEOPLE` บรรทัดที่ไม่มีข้อมูลไม่แสดง ชิดซ้ายเหนือซับ (ซ้าย 56 px ขอบล่าง 520 px) ขึ้นในช็อตที่ใส่ `tag=True` จนจบช็อต (ปกติช็อตที่ 2 ตอนแนะนำตัว)
3. **ซับ** Kanit บรรทัดละวลี บนสุดที่ y 1440 คำที่มี `*…*` เป็นสีเขียว บรรทัดที่มีคำว่า "ไม่มี" เขียวทั้งบรรทัด คำภาษาอังกฤษเขียนเป็นภาษาอังกฤษ (Routine, Set Routine, My HMB, Core Duo, Biotin …)
4. **การ์ดสินค้า** ภาพไดคัตอย่างเดียว ไม่มีกรอบ ไม่มีข้อความ กลางจอเหนือซับต่ำกว่าหน้าคน เรืองแสงเขียวหายใจเป็นจังหวะ ลำแสงหมุน ประกายลอย แกว่งแบบ 3 มิติ `cards=[("set", "m:ss.s")]` (ช่องที่ 3 = วินาที ช่องที่ 4 = `"left"`/`"right"`)
   - `set` = Daily Routine Pack (`routinex-pack.png`) · `hmb` = Protein HMB+ · `flavor` `cocoa` `peach` `midori` = Habix Flavor+ (ภาพจากการ์ด PD-08) · `band` = Xircle Band
5. **ฉากปิด** ภาพสินค้าเรืองแสงเหลืองสดใส ลำแสงเหลืองหมุน ประกายเหลืองวนรอบ หัวเรื่อง 2 บรรทัด ชื่อสินค้า ช่องค้นหา และข้อความกำกับ
   - `E_SET` เซ็ต RoutineX (ภาพกล่องเปิด `routinex-open.png` จากการ์ด PD-03) · `E_HMB` Protein HMB+ · `E_BAND` Xircle (พื้นฟ้าขาว `endbg-xircle.jpg`)
   - พื้นหลัง HabiX ตั้งใน `edl.py` ของโปรเจ็กต์: `END_BG = "endbg-gradient.jpg"` (ไล่สีเขียว) หรือ `"endbg-paper.jpg"` (กระดาษยับ) ไม่ตั้ง = พื้นเขียว HabiX
6. **ไม่มีบรรทัดคำกำกับทุกเฟรม** ข้อความกำกับอยู่ที่ฉากปิดเท่านั้น คำเตือน อย. แบบเต็มจอเปิดด้วย `"fda_warning": true` ใน `project.json` เมื่อจะยิงแอด
7. **ความเร็ว** 1.12 เท่า ทุกตอน หัวคลิปเป็นประโยคเด็ดของคนนั้นเอง (`slam=True`) แล้วค่อยแนะนำตัว

## รหัสภาพในโฟลเดอร์ของแต่ละคน (ภาพแทรก)

ชื่อไฟล์ขึ้นต้นด้วยรหัสตามด้วยเลข เช่น `BF1.jpg` `E3.jpg` `app1.jpg` คัดลอกลง `inserts/<รหัสคน>-<ชื่อ>/` ก่อนใช้ ตั้ง `F = "inserts/<รหัสคน>-<ชื่อ>/"` ใน `edl.py`

| รหัส | คือภาพอะไร | ใส่เมื่อ | วิธีใส่ |
|---|---|---|---|
| `BF` | ก่อน: ตอนน้ำหนักมากที่สุด | พูดถึงตัวเองเมื่อก่อน น้ำหนัก สัดส่วน หุ่น ตัวเลขผลลัพธ์ | `ins=SEQ(F, "BF", "m:ss.s")` = BF ทุกภาพเรียงตามเลข แล้ว AF ทุกภาพต่อท้าย เต็มจอทีละภาพ **เวลาต่อภาพนับแยกกลุ่ม: 3 ภาพขึ้นไป ภาพละ 1 วิ · น้อยกว่า 3 ภาพ ภาพละ 2 วิ** |
| `AF` | หลัง: ตัวเล็กลง น้ำหนักลดลง | มากับ BF เสมอ | อยู่ใน `SEQ(F, "BF", …)` |
| `E` | อาหาร และการทาน Routine | พูดถึงการกิน มื้อ ชง ทาน Routine | `ins=SEQ(F, "E", "m:ss.s")` ภาพละ 1 วิ |
| `M` | ขยับร่างกาย ออกกำลังกาย เดิน วิ่ง ยิม | พูดถึงการขยับ ออกกำลัง | `ins=SEQ(F, "M", "m:ss.s")` ภาพละ 1 วิ |
| `X` | ใส่สายรัดข้อมือ Xircle | พูดถึงสายรัด หรือแอป Xircle | `ins=SEQ(F, "X", "m:ss.s")` ภาพละ 1 วิ |
| `app` | หน้าจอแอป Xircle ของผู้รีวิว | พูดถึงแอป หรือคำว่า Xircle | `apps=[APP(F + "app1.jpg", "m:ss.s", eat=…, move=…, sleep=…, habit=…)]` โทรศัพท์ทางซ้าย ค่าใหญ่ทางขวา |

- `at` คือเวลาในเทปตรงคำที่พูดถึง ชุดภาพเริ่มตรงนั้นแล้ววิ่งข้ามช็อตถัดไปได้ ระหว่างภาพตัดชน จางเข้า-ออกเฉพาะหัวกับท้ายชุด เสียงและซับเดินต่อตามปกติ
- ภาพแนวตั้ง (สูง:กว้าง ≥ 1.3) เต็มจอ ภาพจัตุรัส/แนวนอน เป็นกรอบกลางจอบนพื้นเบลอ ภาพเล็กกว่า 720 px ครอปขอบที่มีตัวหนังสือออก ขยาย 3 เท่าด้วย lanczos แล้ว `fit="panel"`
- ค่า EAT / MOVE / SLEEP / HABIT อ่านจากภาพนั้นจริง อ่านไม่ออกให้เว้น ห้ามแต่ง
- วางชุดภาพให้จบก่อนฉากปิด และไม่ทับ 1.5 วิแรกของคลิป
- ภาพ BF/AF ระดับแดงเสมอ (`rv risk` ติดป้ายเอง) ภาพ X/app เป็นแบรนด์ Xircle ใส่เมื่อทีมสั่ง เขียนใน `risk=` และ `check=` (ใบยินยอมของเจ้าของภาพ) ทีมตัดสินเอง
- แบบวาง BF ซ้าย AF ขวาในเฟรมเดียว (`BA(F, "m:ss.s", pair=True)`) **เลิกใช้แล้ว** ใช้เมื่อเจ้าของสกิลสั่งเป็นครั้ง ๆ เท่านั้น

## คลิปเรื่อง Xircle

- ใส่ `**XIRCLE` ใน `C(...)` และใช้ฉากปิด `E_BAND` ตัวหนังสือและเส้นทุกจุดเปลี่ยนเป็นฟ้า `#4285F4` เอง ป้ายชื่อไม่มีโลโก้ HabiX
- พูดถึงสายรัด / Smart Band → `cards=[("band", "m:ss.s", 2.2)]` · พูดถึงการขยับ → ภาพ `M`
- พูดถึงแอป ฟังก์ชัน การวิเคราะห์ การบันทึกอาหาร → `apps=UISEQ("m:ss.s", keys=(...))` โทรศัพท์ใหญ่ทางซ้าย (540×1000) **แต่ละฉากแอปยาวรวม 4 วิ** (1 ภาพ `each=4.0` · 2 ภาพ `each=2.0`) `home` หน้าแรก · `scan` AI Food Scan · `nutri` ข้อมูลสารอาหาร · `eatlog` Eat Log · `balance` สมดุลพลังงาน
  - สกรีนไม่ได้แนบมากับสกิล (มีข้อมูลจากบัญชีจริง) อ่าน `kit/assets/ui/README.txt` ถ้าไม่มีสกรีน UISEQ จะข้ามและเตือน
- ไม่ใส่ช่วงที่พูดถึงราคา เว้นแต่ทีมสั่ง และราคาต้องตรงราคาทางการ ณ วันโพสต์
- หนึ่งคลิปหนึ่งแบรนด์: เรื่อง HabiX กับเรื่อง Xircle ของคนเดียวกันแยกเป็นคนละตอน

## ต้องมีก่อน

- `ffmpeg`, Node 20+, `uv`, Google Chrome (หรือ `npx playwright install chromium`)
- ครั้งแรก: `cd <skill>/kit && npm install && chmod +x rv` แล้ว `<skill>/kit/rv doctor` ต้องขึ้น "ครบ" (ถ้ารัน `rv` ไม่ได้ ใช้ `bash <skill>/kit/rv …`)
- ถอดเสียง: Mac ชิป Apple ใช้ mlx-whisper · เครื่องอื่น (Windows, Linux, Intel Mac) ใช้ faster-whisper บน CPU (`RV_FW_MODEL` เลือกโมเดล ค่าเริ่ม `large-v3-turbo`) ช้ากว่ามาก: เทป 3.5 นาทีอาจใช้ 20–60 นาที
- Windows: รันใน Git Bash ตั้ง `PYTHONIOENCODING=utf-8` และสั่งชื่อตอนตรง ๆ แทน `ALL` ต้นฉบับ 4K HEVC ให้คัดลอกลงเครื่องก่อน

## กติกาที่ห้ามข้าม

- **ห้ามแต่ง** ชื่อคน อายุ อาชีพ ตัวเลข เลข อย. ราคา ลิงก์ ถ้าเทปไม่ได้พูดหรือไม่มีแหล่งที่อนุมัติ ให้เว้นและบอกว่ายังไม่มี ชื่อที่ฟังไม่ชัดใส่ `check=`
- **ซับต้องตรงเสียง** ห้ามแก้คำพูดให้ฟังดีขึ้น ห้ามต่อคำข้ามประโยคให้เกิดความหมายใหม่ คำที่ฟังไม่ชัดใส่ `check=`
- **หนึ่งคลิป หนึ่งแบรนด์** HabiX ไม่ปน Xircle
- **AI ไม่อนุมัติ** คลิประดับส้ม/แดงต้องให้ผู้รับผิดชอบด้านกฎหมาย/อย. ตัดสิน และผู้รีวิวทุกคนต้องเซ็นยินยอมก่อน
- **ภาพแทรกต้องมีสิทธิ์ใช้** ภาพสินค้าทางการ (มากับสกิลใน `kit/assets/`) หรือภาพที่ผู้รีวิว/ทีมส่งมาในโฟลเดอร์รหัส ไม่ใช้คลิปของคนอื่นจากอินเทอร์เน็ต
- **บอกผลตามจริง** `rv qa` กับ `rv risk` เป็นตัวช่วย ไม่ใช่หูกับนักกฎหมาย ทุกตอนต้องมีคนฟังก่อนเผยแพร่ ขั้นไหนไม่ได้ทำให้บอกว่าไม่ได้ทำ
