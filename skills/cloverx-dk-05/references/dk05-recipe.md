## 3. คำเตือนและข้อความกำกับ (`05-end-hmb-gradient.jpg`, `06-end-set-gradient.jpg`, `08-end-xircle.jpg`)

- ข้อความกำกับอยู่ใต้ช่องค้นหาในฉากปิดเท่านั้น ข้อความอยู่ใน `kit/lib/edlkit.py`:
  - `DISC` (ทั่วไป): ผลิตภัณฑ์เสริมอาหาร ไม่มีผลในการป้องกันหรือรักษาโรค · โปรดอ่านฉลากก่อนบริโภค · ผลลัพธ์แตกต่างกันในแต่ละบุคคล · ความคิดเห็นในคลิปเป็นประสบการณ์ส่วนบุคคลของผู้ใช้
  - `DISC_HMB` (Protein HMB+ และเซ็ต RoutineX): เพิ่ม "เด็กและสตรีมีครรภ์ไม่ควรรับประทาน · มีส่วนประกอบจากนมและถั่วเหลือง"
  - `DISC_X` (Xircle): Xircle ใช้เพื่อติดตามพฤติกรรมสุขภาพ ไม่ใช่การวินิจฉัยโรค · ความคิดเห็นในคลิปเป็นประสบการณ์ส่วนบุคคลของผู้ใช้
- `E_SET` ใช้ `DISC_HMB` เพราะเซ็ตมีซอง Protein HMB+ อยู่ด้วย **ยังไม่ได้เทียบกับฉลากเซ็ต RoutineX ฉบับจริง** ก่อนยิงแอดให้ผู้รับผิดชอบ อย. ตรวจข้อความ
- คำเตือน อย. แบบเต็ม (`FDA_WARN` 3 ข้อ: เด็กและสตรีมีครรภ์ไม่ควรรับประทาน / ไม่มีผลในการป้องกันหรือรักษาโรค / อ่านคำเตือนในฉลากก่อนบริโภค) ขึ้นที่ฉากปิดเมื่อ `"fda_warning": true` ใน `project.json` ใช้เมื่อจะยิงแอด คลิปที่ส่งตรวจภายในหรือส่งทางไลน์ไม่ต้องเปิด คลิป Xircle ไม่ขึ้น

## 4. ภาพสินค้า (`02-product-card-set.jpg`, `04-product-card-flavor.jpg`)

- ภาพทุกภาพอยู่ใน `kit/assets/` เป็นภาพทางการจากการ์ดสินค้า PD ไดคัตพื้นโปร่ง ไม่ต้องโหลดจากที่อื่น
- การ์ดสินค้าระหว่างคลิป: ภาพไดคัตอย่างเดียว ไม่มีกรอบ ไม่มีชื่อสินค้าใต้ภาพ กลางจอเหนือซับ เรืองแสงเขียว (Xircle: ฟ้า) ขึ้นตรงคำที่พูดถึงสินค้า

| คีย์ | ภาพ | ใช้เมื่อพูดถึง |
|---|---|---|
| `set` | `routinex-pack.png` Daily Routine Pack พร้อมซอง | Set Routine / Routine / RoutineX / ซองเดียวครบ |
| `hmb` | `hmb.png` | Protein HMB+ / My HMB / โปรตีน |
| `flavor` · `cocoa` · `peach` · `midori` | `habix-flavor*.png` (การ์ด PD-08) | Flavor+ / ชื่อรส |
| `band` | `xircle-band.png` | สายรัด / Smart Band (คลิป Xircle) |

- ฉากปิด: `E_SET` = กล่องเปิด `routinex-open.png` (การ์ด PD-03) · `E_HMB` = `hmb.png` · `E_BAND` = `xircle-band.png` บนพื้น `endbg-xircle.jpg`
- **`duo.png` คือ Protein HMB+ คู่กับ G.U.S.+ ไม่ใช่เซ็ต RoutineX** ห้ามใช้แทนภาพเซ็ต (คลิปทดสอบรอบก่อนใช้ภาพนี้ในฉากปิด "เซ็ต RoutineX")
- ฉากปิด HabiX ใช้พื้นหลัง `END_BG = "endbg-gradient.jpg"` (ไล่สีเขียว) หรือ `"endbg-paper.jpg"` ไม่ใช่พื้นดำ ภาพสินค้าเรืองแสงเหลืองสดใสหายใจเป็นจังหวะ ลำแสงหมุน ประกายวนรอบ โลโก้ HabiX ใหญ่ด้านบน

## 5. ภาพแทรก (`03-insert-bf.jpg`, `03-insert-af.jpg`)

- ภาพมาจากโฟลเดอร์ของผู้รีวิวคนนั้น ตั้งชื่อด้วยรหัส `BF` `AF` `E` `M` `X` `app` ตามด้วยเลข ตารางเต็มอยู่ใน `SKILL.md`
- BF/AF: เต็มจอทีละภาพ BF ทุกภาพก่อน แล้ว AF ทุกภาพ แต่ละกลุ่ม 3 ภาพขึ้นไปภาพละ 1 วิ น้อยกว่า 3 ภาพภาพละ 2 วิ วางตรงคำที่พูดถึงตัวเลข น้ำหนัก หรือหุ่น (ตัวอย่างงานจริง: BF1+AF1 วางที่ "น้ำหนักจาก 66.4 เหลือ 61.4" = BF 2 วิ แล้ว AF 2 วิ)
- E (อาหาร) ตรงคำว่ากิน/มื้อ · M (ออกกำลัง) ตรงคำว่าขยับ/เดิน/ออกกำลัง · X (สายรัด) ตรงคำว่าสายรัด/Smart Band ภาพละ 1 วิ
- app: โทรศัพท์ทางซ้าย ค่า EAT/MOVE/SLEEP/HABIT ที่อ่านจากภาพจริงทางขวา · สกรีนแอปทางการ (UISEQ) ฉากละ 4 วิ
- ภาพแทรกต้องมีครบก่อนตัด ถ้าโหลดภาพในโฟลเดอร์ไม่ได้ (ไม่ได้แชร์) ให้หยุดถามคนสั่งงาน อย่าตัดต่อโดยไม่มีภาพแล้วรายงานว่าเสร็จ

## 6. ต่อคนได้กี่ตอน

ไม่มีจำนวนตายตัว คนสั่งงานเป็นคนบอกว่าจะเอาตอนไหน ถ้าไม่ได้บอก ให้เสนอจากเนื้อหาเทปตามแบบนี้แล้วถามก่อนเรนเดอร์:

| ตอน | เมื่อไหร่ | ตัวอย่างจากงานจริง |
|---|---|---|
| `G01` (`G02`…) | เรื่องเดียวของคนนั้น ไม่มีตัวเลขผลลัพธ์ ฉากปิดสินค้าที่พูดถึงมากที่สุด | "แค่ซองเดียว อิ่มนาน" 38 วิ |
| `Y01` | มีตัวเลขผลลัพธ์ (ไขมัน น้ำหนัก สัดส่วน) หรือภาพ BF/AF หรือคำระดับส้ม/แดงที่ทีมสั่งให้ใส่ | "หนึ่งเดือนลดได้ 7%" 33 วิ ภาพ BF/AF ตรงตัวเลข |
| `X01` | ผู้รีวิวพูดถึง Xircle (สายรัด แอป) แยกจากเรื่อง HabiX เสมอ | "เหมือนมีโค้ชส่วนตัว" 50 วิ |
| `S01` | ทีมเลือกประโยคเองจากถอดเสียง ตัดตามลำดับนั้น ยาวเกิน 32 วิได้ | เรื่องเล่าเต็ม |

- เทปของคนเดียวกันมีหลายไฟล์ ให้ดูทุกไฟล์ที่เป็นเทปพูด (ไม่ใช่แค่ไฟล์หลัก) ต่อกันเป็น `tape.mov` แล้วใส่ `parts` ใน `project.json`
- ความยาวตอน G/Y ปกติ 25–40 วิ รวมฉากปิด ตอน X/S ยาวได้ถึงราว 50 วิ

## 7. จังหวะและการตัด

- ช็อตแรก = ประโยคเด็ดของคนนั้น (`slam=True`) ซับตัวใหญ่ จากนั้นช็อตแนะนำตัว (`tag=True`) "สวัสดีค่ะ ชื่อ…" แล้วค่อยเล่าเรื่อง ปิดด้วยประโยคสรุปแบบ `"B"`
- ตัดชิดคำ (`snap=False` เมื่อเล็งเวลาเองจาก `rv words`) ไม่กินเสียงพิธีกร ไม่ต่อคำข้ามประโยคให้ความหมายเปลี่ยน
- ความเร็ว 1.12 เท่า ซูมเดินตามจังหวะ `ZCYCLE` เสียงเอฟเฟกต์ตอนเปิด ตอนการ์ดขึ้น และตอนภาพแทรกเข้า
- ทุกตอนต้องมี `risk=` (ระดับที่รู้) และ `check=` (คำที่ฟังไม่ชัด ตัวเลขที่ต้องฟังยืนยัน ใบยินยอม)
