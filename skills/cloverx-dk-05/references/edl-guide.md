# เขียน edl.py

`edl.py` คือรายการตัดทั้งหมดของโปรเจ็กต์ แก้ไฟล์นี้ที่เดียว แล้วสั่ง `rv make <ตอน>` เวลาทุกค่าเป็นเวลาในเทปต้นทาง `"นาที:วินาที.ทศนิยม"`

```python
from edlkit import *

PEOPLE = {                       # รหัสสั้น → ป้ายชื่อ และ x = ตำแหน่งหน้าในเฟรม (0 ซ้าย … 1 ขวา)
    "a1": dict(name="คุณเอ", age="อายุ 48 ปี", job="อาชีพ พยาบาล", x=0.55),   # V.2: ป้าย 3 บรรทัด ชื่อ / อายุ / อาชีพ (ไม่รู้ให้เว้น "" ห้ามแต่ง)
    "b1": dict(name="คุณบี", role="อายุ 45", x=0.58),
}

C("G03", ["ถ้ายังไม่ลอง", "*คุณพลาด*"], [                     # รหัสตอน, หัวเรื่อง 2 บรรทัด
    P("5:52.98", "5:55.30", "a1", slam=True, tag=True,
      subs=["ถ้าคุณยังไม่ลองนะ", ("*คุณพลาด*", "B")]),
    P("4:16.70", "4:26.30", "a1",
      subs=["จริงๆ เนี่ย", "ชอบหมดทุกตัวเลยนะคะ", "นั่นก็คือตัว*แอสต้า*ค่ะ"], cards=[("asta", "4:24.6")]),
    P("5:55.92", "5:57.45", "a1", subs=[("คุณ*ต้องลอง*นะคะ", "B")]),
  ], E_SET, title="ถ้าคุณยังไม่ลอง คุณพลาด", product="เซ็ต RoutineX", level="G")
```

## P(เริ่ม, จบ, คน, …) หนึ่งช็อต

| ช่อง | ความหมาย |
|---|---|
| คน | รหัสใน `PEOPLE` หรือ `("รหัส", x)` เมื่อคนเดิมยืนคนละตำแหน่งในช่วงนั้น |
| `subs=[…]` | ข้อความซับที่พิสูจน์อักษรแล้ว เรียงตามที่พูด ระบบจับเวลาเองจากผลถอดเสียง · `("…", "B")` ซับใหญ่ · `("…", "Q")` เสียงพิธีกรแทรก · ไม่ใส่ = ใช้ผลถอดเสียงดิบ (ใช้ดูเฉยๆ ห้ามปล่อย) |
| `q=True` | ทั้งช็อตเป็นเสียงพิธีกร |
| `slam=True` | ซูมกระแทก ใช้กับช็อตเปิด |
| `tag=True` | ป้ายชื่อจาก `PEOPLE` (หรือใส่ `("ชื่อ", "บรรทัดรอง")`) ช็อตสั้นกว่า 1 วิ ไม่ขึ้น |
| `cards=[("hmb", "4:24.6")]` | การ์ดสินค้าจาก `PRODUCTS` ขึ้นที่เวลานั้น (หรือเป็นวินาทีนับจากต้นช็อต) |
| `z=1.0` | ล็อกระดับซูม (ช็อตหลายคน) |
| `snap=False` | ไม่ขยับจุดตัดอัตโนมัติ ใช้กับช็อตสั้นหรือจุดที่เล็งเองแล้ว |
| `tight=False` | ไม่ตัดช่วงเงียบในช็อต |
| `ins=[dict(file=…, at=0.4, dur=2.2)]` | insert รอบ 2 (ดู insert-round2.md) |

## C(รหัส, หัวเรื่อง, ช็อต, ฉากปิด, …) หนึ่งตอน

- ฉากปิดสำเร็จรูป: `E_HMB`, `E_GUS`, `E_SET`, `E_BAND` หรือสร้างเองด้วย `END(title, sub, search, img=…)`
- `title=` ชื่อในหน้าตรวจงาน · `product=` สินค้าในตอน · `level="Y"` + `risk="…"` สำหรับตอนที่มีตัวเลขผลลัพธ์ · `check="…"` คำที่ฟังไม่ชัด ให้คนฟังซ้ำ
- ตอนของ Xircle: เพิ่ม `**XIRCLE` (หัวมุมและบรรทัดกำกับเป็นของ Xircle) และใช้ `E_BAND`
- `kw=[…]` คำสีทองเพิ่มเฉพาะตอน · `music_under_db=20` ระยะที่เพลงเบากว่าเสียงพูด

## ของแบรนด์อื่น

เพิ่มใน `edl.py` ของโปรเจ็กต์ได้เลย: `PRODUCTS["ชื่อ"] = ("ไฟล์ใน assets/", "ชื่อสินค้า", "บรรทัดรอง")`, `KW += [r"คำ"]`, ฉากปิดใหม่ด้วย `END(…)` และวางภาพใน `assets/` ของโปรเจ็กต์ (ทับของ kit ได้ด้วยชื่อไฟล์เดียวกัน) ข้อความกำกับ (`DISC`, `NOTE`) ต้องมาจากข้อมูลที่แบรนด์อนุมัติ
