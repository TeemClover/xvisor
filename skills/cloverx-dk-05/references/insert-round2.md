# รอบ 2: insert ให้ถูกคน

ตัดคลิปก่อน แล้วให้คนรับผิดชอบหาภาพ คลิป ฟุตเทจ คลิปสินค้า และสกรีนช็อตแอป Xircle มาแบ่งโฟลเดอร์ตามคน พร้อมภาพแคปจากหน้า HTML ว่าเป็นของคนไหน รอบ 2 จึงใส่ insert ได้ถูกคน

## ทางหลัก: หน้าจับคู่ (คนทำแค่หน้าเดียว)

เพิ่มเมื่อ 20 พ.ย. 2569 จากงานจริง: ทีมส่งโฟลเดอร์ Drive ที่มีภาพ 33 ไฟล์ ชื่อไฟล์เป็นตัวเลข ไม่มีโฟลเดอร์ย่อย การให้คนนั่งแบ่งโฟลเดอร์เองเปลืองแรง จึงเปลี่ยนเป็นให้ AI เตรียมทุกอย่างแล้วคนตัดสินในหน้าเดียว

| ขั้น | ใคร | ทำอะไร |
|---|---|---|
| 1 | คนหา insert | โยนไฟล์ทั้งหมดลง `inserts/_inbox/` หรือส่งลิงก์ Drive |
| 2 | AI | ดูทุกไฟล์ รวมเป็นชุดตามคน เขียน `inserts/_inbox/pairing.json` แล้ว `rv inserts page` |
| 3 | ผู้ตรวจ | เปิด `จับคู่-insert.html` เลือกว่าแต่ละชุดคือใคร ชนิดไหน ใช้แบบไหนได้ ตอบคำถาม กดบันทึกหรือคัดลอก prompt |
| 4 | AI | `rv inserts apply <ไฟล์ที่บันทึก>` → วาง `ins=` → `rv make` → `rv qa` → `rv risk` → `rv inserts page` |

`pairing.json`:

```json
{"title": "…", "verdict": ["สิ่งที่ AI พบ ข้อละบรรทัด (ใส่ <b> ได้)"], "questions": ["คำถามถึงผู้ตรวจ"],
 "duplicates": ["ไฟล์ซ้ำที่ไม่ต้องอยู่ในชุดไหน"],
 "sets": [{"id": "A", "files": ["a.jpg", "b.jpg"], "desc": "สิ่งที่เห็นในภาพ", "guess": "รหัสคน | none | \"\"", "use": "single | ba | \"\"", "note": ""}]}
```

- **ห้ามจับคู่คนจากใบหน้า** `guess` ใส่ได้เมื่อภาพเองบอก: ชื่อหรืออายุที่เขียนในภาพ แคปชัน สินค้าในฉาก ถ้าไม่มี ให้เว้นว่างแล้วให้คนเลือก
- `desc` เขียนจากสิ่งที่เห็น (ทรงผม เสื้อ ฉาก ข้อความในภาพ) เพื่อให้คนหาเจอเร็ว ไม่ใส่การคาดเดาเรื่องสุขภาพหรือรูปร่าง
- ตอนที่ใส่ insert ให้ตั้งชื่อตอนเดิมต่อท้ายด้วย `i` (`G07i`) ตอนเดิมไม่ถูกทับ หน้าจับคู่จะโชว์ทุกตอนที่มี insert พร้อมช่องความเห็น

## ทางเดิม: แบ่งโฟลเดอร์เอง

### ใครทำอะไร

| ขั้น | ใคร | ทำอะไร |
|---|---|---|
| 1 | AI | `rv inserts init` สร้าง `inserts/<รหัส>-<ชื่อ>/` ให้ทุกคนใน `PEOPLE` พร้อมรูปหน้า `คนนี้คือใคร.jpg`, `อ่านก่อน.txt` (รายการช็อตของคนนั้น) และ `inserts/คำขอ-insert.md` |
| 2 | ผู้ตรวจ | เปิด `ตรวจงาน.html` พิมพ์ใน "โน้ตถึงคนหา insert" ของแต่ละช่องว่าอยากได้อะไร แล้วบันทึกหน้า |
| 3 | คนหา insert | วางไฟล์ลงโฟลเดอร์ของคนนั้นตามชนิด และแคปการ์ดคนนั้นจากส่วน "คนในคลิป" ของหน้า HTML วางไว้ที่ชั้นบนของโฟลเดอร์ |
| 4 | AI | `rv inserts scan` ตรวจไฟล์ เสนอช่อง แล้ววาง `ins=` ใน `edl.py` → `rv make` → `rv qa` → `rv risk` → `rv report` |
| 5 | ผู้ตรวจ | ตรวจตอนที่ใส่ insert แล้วในหน้า HTML ชุดใหม่ |

## โฟลเดอร์

```
inserts/
  a1-คุณเอ/            ← หนึ่งคน หนึ่งโฟลเดอร์ (ชื่อขึ้นต้นด้วยรหัสคน ห้ามเปลี่ยนรหัส)
    คนนี้คือใคร.jpg      ← รูปหน้าที่ระบบจับให้
    (ภาพแคปการ์ดจาก HTML) ← วางที่ชั้นนี้ ตั้งชื่ออะไรก็ได้ ระบบไม่เอาไปใส่คลิป
    1-สินค้า/            ภาพหรือคลิปสินค้า: ซอง กล่อง ฉลาก
    2-การใช้/            แกะซอง ชง ดื่ม พกพา
    3-แอป-Xircle/        สกรีนช็อตหรืออัดหน้าจอแอป
    4-ภาพและฟุตเทจ/      ภาพหรือฟุตเทจของคนนี้
    5-อื่นๆ/
  _กลาง/                ← ของที่ใช้กับช็อตของใครก็ได้ (สินค้า การใช้ แอป) ห้ามวางภาพตัวบุคคลที่นี่
  คำขอ-insert.md         รายการช่องของทุกคน
```

- อยากให้ลงช็อตไหนแน่ๆ ให้ขึ้นต้นชื่อไฟล์ด้วยรหัสช่อง: `G03-2_แกะซอง.mp4` (รหัสช่องดูใต้คลิปในหน้า HTML)
- ไฟล์ที่ใช้ได้: mp4 mov jpg png webp (HEIC ต้องแปลงก่อน) ด้านสั้นอย่างน้อย 720 px
- ระบบ **หยุดทันที** ถ้าไฟล์จากโฟลเดอร์ของคนหนึ่งถูกวางในช็อตของอีกคน

## วางลงคลิป

```python
P("4:16.70", "4:26.30", "a1", subs=[…],
  ins=[dict(file="inserts/a1-คุณเอ/2-การใช้/G03-2_แกะซอง.mp4", at="4:22.6", dur=2.2)])
```

- `at` = เวลาในเทป (ตรงคำที่เอ่ยถึงสิ่งนั้น) หรือวินาทีนับจากต้นช็อต · `dur` 1.5–3 วิ · `ss` = เริ่มเล่นคลิป insert จากวินาทีที่เท่าไร
- `fit="cover"` เต็มจอ (ภาพ/คลิปแนวตั้ง) · `fit="panel"` กรอบกลางจอบนพื้นเบลอ (แนวนอน สี่เหลี่ยม สกรีนช็อต) · `fit="below"` วางภาพใต้หัวเรื่อง ใช้เมื่อหน้าคนอยู่ขอบบนของภาพแล้วโดนหัวเรื่องบัง ไม่ใส่ = เลือกให้ตามสัดส่วน
- เสียงพูดเดินต่อ ซับ หัวเรื่อง ยังอยู่บน insert เสมอ

## กติกาให้ดูไม่สะดุด

1. insert ต้อง **ตรงกับคำที่กำลังพูด**: เอ่ยชื่อสินค้า → ภาพสินค้า, พูดถึงการชง → คลิปชง, พูดถึงแอป → หน้าจอแอป ถ้าไม่มีของที่ตรง ไม่ต้องใส่
2. ไม่ทับ 1.5 วินาทีแรกของคลิป ไม่ทับซับใหญ่ และไม่ทับช็อตที่สีหน้าผู้รีวิวคือจุดขาย
3. รวมกันไม่เกินราว 1 ใน 3 ของคลิป และไม่ติดกัน 2 อัน (ยกเว้นคู่ก่อน–หลังที่ผู้ตรวจสั่งให้ขึ้นติดกันเพื่อเทียบ)
4. ช็อตที่มี insert แล้วไม่ต้องมีการ์ดสินค้าซ้ำ (ระบบตัดการ์ดที่ชนให้)
5. สกรีนช็อตแอปต้องเป็นบัญชีตัวอย่างหรือของผู้รีวิวเองที่ยินยอม ไม่มีข้อมูลสุขภาพของคนอื่น และคลิปที่โชว์แอปต้องมีบรรทัด "ใช้ติดตามพฤติกรรมสุขภาพ ไม่ใช่การวินิจฉัยโรค"
6. ระดับแดง: ภาพก่อน–หลัง ภาพที่มีตัวเลขน้ำหนัก ไขมัน หรือจำนวนวัน ภาพสายวัดหรือเครื่องชั่ง ภาพจับพุง (ติดข้อห้ามโฆษณาอาหารของ อย. และกติกาแพลตฟอร์ม) AI ต้องเตือนทุกครั้ง ใช้ได้เฉพาะชุดที่ผู้ตรวจเลือก "ใช้ภาพก่อน–หลังได้" ในหน้าจับคู่ และเขียนใน `check=` ว่าเป็นระดับแดง · ห้ามใช้เสมอ: ฟุตเทจที่ไม่มีสิทธิ์ใช้ ภาพของคนที่ยังไม่ยินยอม และภาพขวด แก้ว หรือโลโก้เครื่องดื่มแอลกอฮอล์
7. หลังใส่ insert ต้อง `rv risk` และให้คนดูซ้ำทุกตอนที่เปลี่ยน
