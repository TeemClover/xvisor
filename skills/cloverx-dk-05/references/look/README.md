# ภาพอ้างอิงหน้าตา DK-05

ภาพนิ่งจากคลิป DK-05 ที่ตัดและผ่านการดูจริง (ขนาดครึ่งหนึ่งของ 1080×1920) ใช้เทียบหลังเรนเดอร์ทุกครั้ง
เพื่อไม่ให้มีหน้าผู้รีวิวในโฟลเดอร์สกิล ภาพส่วนใหญ่เป็นเลเยอร์ตัวหนังสือวางบนพื้นเทาที่มีเงาคน ภาพแทรก BF/AF ทำเป็นภาพหยาบ และป้ายชื่อใช้ชื่อตัวอย่าง ในคลิปจริงพื้นหลังคือวิดีโอของผู้รีวิว
