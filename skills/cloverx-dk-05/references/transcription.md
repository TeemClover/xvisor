# ทำให้ซับภาษาไทยแม่น (เสียงจากงานอีเวนต์)

โปรแกรมถอดเสียงพลาดบ่อยกับเสียงในงาน: ชื่อสินค้าเพี้ยน ข้ามประโยค เวลาคลาด AI ไม่มีหู สูตร DK-05 ถอดเสียงทั้งเทปครั้งเดียว แล้วถอดซ้ำเฉพาะที่จำเป็น และบอกคนเมื่อยังไม่แน่ใจ

1. **รอบทั้งเทป** `rv prep` → `work/transcript/lines.txt` ใช้คัดช็อตและรู้ช่วงเวลาคร่าวๆ ห้ามคัดลอกไปเป็นซับตรงๆ
2. **เวลาของคำ** `rv words 12:18-12:50` ดึงคำพร้อมเวลาจากผลถอดเสียงทั้งเทป (ไม่ถอดใหม่ เสร็จในไม่กี่วินาที) ถ้าช่วงไหนข้อความขาดหรือเพี้ยนจนเขียนซับไม่ได้ ค่อยสั่ง `rv words --fresh 12:18-12:50` ถอดเฉพาะช่วงนั้นใหม่ ถ้าผลออกมาเป็นคำซ้ำๆ แปลว่าโมเดลหลอน ให้ทิ้งผลช่วงนั้น
3. **จุดตัด** `rv runs 12:36-12:46` แสดงช่วงที่มีเสียงพูดและช่องเงียบ (ตัวเลขหลัง · คือความยาวช่องเงียบ) เล็งจุดเริ่ม/จบในช่องเงียบ 0.12 วิขึ้นไป
4. **เขียนซับเอง** ใน `subs=[…]` จากผลถอดเสียง สะกดชื่อสินค้าตามที่แบรนด์ใช้ ระบบจะจับเวลาให้จากผลถอดเสียงที่ตรงกับข้อความมากที่สุด
5. **ฟังซ้ำหลังตัด** `rv qa <ตอน>` ถอดเสียงของคลิปที่ตัดแล้วหนึ่งรอบ (ความเร็วจริง) เทียบกับซับ ดู 3 อย่าง: คำต้นช็อตหาย = จุดเริ่มช้าไป · มีเศษคำเกิน = จุดตัดกินประโยคข้างเคียง · คำไม่ตรง = แก้ซับหรือใส่ `check=`
6. คำที่อ่านได้ไม่ตรงกันระหว่างรอบ และตัดสินไม่ได้: เลือกแบบที่ได้ยินบ่อยกว่า แล้วใส่ `check="คำว่า … ฟังไม่ชัด"` ให้คนฟัง

ข้อควรรู้: โมเดลมักทิ้งคำแรกของไฟล์สั้นๆ และหลอนเมื่อใส่คำนำ (initial prompt) กับคลิปสั้น จึงไม่ใส่ · ตัวเลขและชื่อเฉพาะต้องให้คนยืนยันเสมอ · `rv qa` อ่านไม่ออกไม่ได้แปลว่าคลิปผิด ให้รายงานว่า "ยังไม่ได้ยืนยันช่วงนี้"
