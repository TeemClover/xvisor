# วิธีทำคลิปสั้น (ชุดพร้อมถ่าย)

ใช้กับคลิปแนวตั้ง (9:16) ยาว 20–45 วินาที สำหรับ TikTok, Reels, Shorts, LINE VOOM

ในงานที่ส่งให้ผู้ใช้ เรียก Hook ว่า "ประโยคเปิด" เรียก CTA ว่า "ชวนทำต่อ" และเรียก 9:16 ว่า "คลิปแนวตั้ง"

## 1. เลือกวิธีให้เอง ตามของที่ผู้ใช้มี

| ผู้ใช้มี | วิธีทำที่แนะนำ |
|---|---|
| รูปสินค้า 1–5 รูป ไม่อยากออกกล้อง | **สไลด์เล่าเรื่อง** รูปแต่ละรูป 3–5 วินาที เสียงพากย์หรือข้อความบนจอ |
| วิดีโอสั้นจากมือถือ (มือจับ เครื่อง หน้าจอแอป) | **คลิปมือ+พากย์** ใช้ภาพมือและของจริง พากย์ทับ |
| ยอมออกกล้อง หรืออยากทำรีวิว | **พูดหน้ากล้อง 20–30 วินาที** + ภาพสินค้าหรือแคปแอปแทรก |
| คลิปพูดรีวิวที่ถ่ายแล้ว + แคปหน้าจอแอป | **รีวิวจริง** คลิปพูดสลับภาพแทรก ส่งเป็น "ลำดับตัด" ตาม `edit-and-review.md` |
| มีแค่หัวข้อ | **ข้อความบนพื้นสี** แต่ละบรรทัดขึ้นทีละจังหวะ แล้วขอรูปสินค้าจากหน้าโลโก้และภาพ |

ถ้าผู้ใช้บอกพอแล้วให้เลือกวิธีเอง แล้วบอกสั้น ๆ ว่าเลือกอะไรเพราะอะไร ถามได้ไม่เกิน 2 ข้อ ตามลำดับนี้ (ข้ามข้อที่ผู้ใช้บอกแล้ว):
1. พี่มีอะไรอยู่ในมือถือแล้วบ้าง (ยังไม่ได้ถ่าย อยากได้บทรีวิว / ถ่ายคลิปพูดแล้ว / มีแต่รูป) แนบรูปหรือแคปได้ คลิปวิดีโอไม่ต้องแนบ
2. ถ้ามีคลิปพูดแล้ว ถามว่าในคลิปพี่พูดอะไรบ้าง (ดู `edit-and-review.md`) และเลือกผู้ชมเอง ถ้าเป็นทางอื่น ถามว่าคลิปนี้ให้ใครดู (ผู้ชมกลุ่มเดียว)

ตอนท้ายคลิปใช้ค่าเริ่มต้น "ชวนเซฟไว้" ไม่ต้องถาม ถ้าผู้ใช้อยากได้แบบอื่น (ทักไลน์ ดูหน้าสินค้า) ค่อยเปลี่ยน

## 2. โครงคลิป

1. **คำสัญญา 1 บรรทัด** ผู้ชมกลุ่มเดียว ปัญหาเดียว สิ่งที่จะได้หลังดูจบ
2. **ประโยคเปิด (0–3 วินาที)** ต้องเฉลยว่าคลิปนี้เกี่ยวกับอะไร ให้ 2 แบบ ให้ผู้ใช้เลือก
3. **เนื้อหา (3–25 วินาที)** 2–3 ประเด็น ประโยคละไม่เกิน 12 คำ
4. **ชวนทำต่อ (ท้ายคลิป)** ชวนทำสิ่งเดียว เช่น "เซฟไว้ดูตอนชั่งน้ำหนักครั้งหน้า"
5. คำสัญญาในประโยคเปิดต้องจบในคลิป ภาพ เสียง ข้อความ ต้องพูดเรื่องเดียวกัน

ความเร็วพูดภาษาไทย ประมาณ 3–4 คำต่อวินาที บท 30 วินาที ไม่เกิน ~100 คำ

## 3. ชุดพร้อมถ่าย (รูปแบบที่ส่งมอบ)

ส่งตามนี้ เขียนสั้น อ่านบนมือถือได้ กรอบด้านล่างคือแบบฟอร์มให้คุณดู ตอนส่งจริงให้ส่งเป็นข้อความธรรมดา ไม่ใส่กรอบ ยกเว้นแคปชันกับแฮชแท็ก ให้แยกไปใส่กรอบคัดลอก 1 กรอบท้ายงาน (ดู "กรอบคัดลอก" ใน SKILL.md):

```
ชื่อคลิป:
วิธีทำ: (สไลด์เล่าเรื่อง / คลิปมือ+พากย์ / ...) · คลิปแนวตั้ง ~NN วินาที

ประโยคเปิด (เลือก 1)
 1) ...
 2) ...

บท + ช็อต
 0:00–0:03  ภาพ: ...  พูด: ...  ข้อความบนจอ: ...
 0:03–0:10  ภาพ: ...  พูด: ...  ข้อความบนจอ: ...
 ...

แคปชัน: (ไม่เกิน 3 บรรทัด)
แฮชแท็ก: (3–5 อัน ไม่มีขีดกลาง เช่น #XVISOR)
ชวนทำต่อ:

ตรวจคำเสี่ยง: ผ่าน / ต้องแก้ → (บอกประโยคที่แก้)
พี่ต้องใส่หรือยืนยันเอง: [ ... ]
```

ข้อควรจำ:
- ภาพต้องเป็นภาพที่ผู้ใช้มีจริงหรือภาพจากหน้าโลโก้และภาพ (ดู `assets.md`) ห้ามสมมติว่าผู้ใช้มีภาพที่ไม่ได้บอก
- ถ้าต้องมีประสบการณ์ส่วนตัว ให้เว้น `[ใส่ประสบการณ์จริงของพี่]` ห้ามแต่งเอง
- ตัวเลขทุกตัวต้องมีแหล่งจาก `products.md` หรือผู้ใช้ให้มา ไม่งั้นตัดออก
- ผู้ชมที่ยังไม่รู้จักสินค้า ให้เล่าจากสิ่งที่เขาทำอยู่แล้ว (เช่น ชั่งน้ำหนักทุกเช้า) ไม่ใช่เริ่มจากชื่อสินค้า

## 4. แก้ด้วยคำของผู้ใช้

เมื่อผู้ใช้ขอ "เหมือนพี่เล่าให้เพื่อนฟัง" ให้: ตัดศัพท์ทางการ ใช้คำพูดจริง ประโยคสั้นลง ใส่คำเชื่อมแบบพูด เช่น "คือ" "แบบว่า" ได้นิดหน่อย แต่ข้อเท็จจริงและขอบเขตคำเสี่ยงต้องคงเดิม แล้วโชว์ก่อน/หลังแค่ประโยคที่เปลี่ยน

## 5. ตรวจก่อนส่ง

- ผู้ชมกลุ่มเดียว ปัญหาเดียว
- ประโยคเปิดเฉลยตั้งแต่ 3 วินาทีแรก
- พูดถึงผลเมื่อไร มี "ผลของแต่ละคนไม่เหมือนกัน"
- งานที่ส่งให้ผู้ใช้ไม่มีคำว่า Hook, CTA, 9:16
- ไม่มีคำในรายการห้ามของ `claims.md`
- ไม่มีราคา โปรโมชัน เลขสารบบ ที่ผู้ใช้ยังไม่ได้ตรวจ (ถ้ามี ต้องมีลิงก์ให้ตรวจ)
- ทุกช็อตมีภาพที่ผู้ใช้มีจริง
