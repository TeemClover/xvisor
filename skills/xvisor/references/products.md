# ข้อมูลสินค้า CloverX (ฉบับให้ X-VISOR ใช้ทำสื่อ)

สถานะข้อมูล: สรุปจากหน้าเว็บสาธารณะของ CloverX และ myClover ณ วันที่ในไฟล์ `version.md`
ก่อนโพสต์ ราคา โปรโมชัน สต็อก ปริมาณต่อหน่วย สารก่อภูมิแพ้ คำเตือน ต้องตรวจกับหน้าสินค้าทางการหรือฉลากบนแพ็กจริงทุกครั้ง ข้อมูลที่ไม่มีในไฟล์นี้ให้ตอบว่า `[รอยืนยัน]` พร้อมลิงก์หน้าทางการ

## เล่า CloverX ให้จบใน 30 วินาที
CloverX เชื่อมข้อมูลสุขภาพ กิจวัตร สินค้า และคนที่ช่วยติดตามไว้ด้วยกัน แอป XIRCLE, Band และ Scale ช่วยให้คนเห็นพฤติกรรมและแนวโน้มของตัวเอง HabiX เป็นกลุ่มสินค้า RoutineX จัดสินค้าบางรายการไว้ด้วยกันสำหรับกิจวัตรประจำวัน X-VISOR คือคนที่ผ่านการอบรมและรับรองจาก CloverX ช่วยให้สมาชิกอ่านข้อมูล เลือกสิ่งที่ทำต่อ และกลับมาทบทวนด้วยกัน
เริ่มจากสิ่งที่คนทำอยู่แล้ว เช่น คนที่อยากนอนตรงเวลา ดูเวลานอนจริงหนึ่งสัปดาห์ เลือกเป้าหมายเล็ก ๆ แล้วกลับมาดูแนวโน้ม

## แผนที่ระบบ

| ชื่อ | ทำหน้าที่อะไร |
|---|---|
| XIRCLE App | รวมข้อมูลจากอุปกรณ์และสิ่งที่ผู้ใช้บันทึก ให้เห็นภาพกิจวัตรและแนวโน้ม |
| XIRCLE Band | ติดตามการเคลื่อนไหว การนอน และสัญญาณที่อุปกรณ์รองรับ |
| XIRCLE Scale | วัดน้ำหนักและประเมินองค์ประกอบร่างกายเพื่อดูแนวโน้ม |
| HabiX | กลุ่มสินค้าเสริมอาหารและตัวเพิ่มรสสำหรับโปรตีนชงดื่ม |
| RoutineX | เซ็ตสำหรับกิจวัตรประจำวัน บริษัทอธิบายไว้ในกรอบ 28 วัน |
| X-VISOR | คนที่ผ่านการอบรมและรับรองจาก CloverX ช่วยอธิบายข้อมูลและติดตามกิจวัตร |

จำง่าย: Band = กิจกรรมและการนอน · Scale = น้ำหนักและองค์ประกอบร่างกาย · App = รวมภาพจากหลายแหล่ง

## XIRCLE Scale (ตัวอย่างที่ใช้บ่อยในคลิป)
- ข้อมูลที่เห็นบนกล่องและเว็บ: เชื่อมต่อแอป (App Sync), องค์ประกอบร่างกาย (Body Composition), สรุปรายสัปดาห์ (Weekly Insight), พื้นกระจก ITO ยืนตรงจุดไหนก็วัดได้ตามที่กล่องระบุ
- ใช้เล่าเรื่อง "ดูแนวโน้มของตัวเอง" ได้ ไม่ใช้วินิจฉัยโรค และไม่สัญญาผลลัพธ์
- Habit Score คือคะแนนพฤติกรรม Eat · Move · Sleep ส่วน Body Composition อ่านแยกกัน อย่าเอามารวมเป็นคะแนนเดียว
- วิธีเชื่อมต่อ ดูวิดีโอทางการ: https://www.youtube.com/watch?v=4WHeeCpmxuM
- รายละเอียดอุปกรณ์: https://www.cloverx.co.th/th/xircle

## ขั้นตอนก่อนให้ข้อมูลลูกค้า
1. ฟังเป้าหมาย ถามเท่าที่จำเป็น
2. ดูกิจวัตรและอาหารปกติก่อน แล้วค่อยบอกว่าสินค้าแต่ละตัวมีหน้าที่อะไรในกิจวัตรนั้น
3. เปิดต้นฉบับ ตรวจชื่อสินค้า รุ่น หน่วยบริโภค คำเตือน
4. ตอบตามหลักฐาน แยกส่วนประกอบออกจากคำอ้างเรื่องผล ส่งคำถามเรื่องโรค ยา อาการ ให้บุคลากรสุขภาพ
5. ตกลงสิ่งที่จะลองหนึ่งอย่างและเวลาทบทวน
