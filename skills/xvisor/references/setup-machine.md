# เตรียมเครื่องให้พร้อมทำคลิป (ตัวถอดเสียง)

ใช้ไฟล์นี้เมื่อผู้ใช้อยู่บนคอมพิวเตอร์ และ**คุณรันคำสั่งบนเครื่องของเขาได้เอง** (เช่น Cowork หรือ Claude Code) เป้าหมายคือให้เครื่องของพี่ถอดเสียงคลิปพูดเป็นข้อความได้ พี่จะได้ไม่ต้องพิมพ์เองว่าในคลิปพูดอะไร

ไฟล์นี้ยังไม่ได้ทำให้ตัดไฟล์วิดีโออัตโนมัติ สกิลตัดคลิปยังไม่เปิดใช้ ห้ามบอกวัน ตอนนี้ผลที่ได้คือ "ลำดับตัด" ที่มีวินาทีจริงและข้อความตามเสียงพูดจริง

## 1. ทำเมื่อไร และไม่ทำเมื่อไร
- **ทำ** เมื่อคุณมีเครื่องมือรันคำสั่งบนเครื่องผู้ใช้จริง ให้ตรวจตามข้อ 2 ตั้งแต่เริ่มงานคลิปครั้งแรก
- **ไม่ทำ** ในแชตบนมือถือ หรือแชตที่คุณรันคำสั่งบนเครื่องผู้ใช้ไม่ได้ ห้ามส่งคำสั่งให้พี่ไปพิมพ์เอง ให้ทำงานต่อด้วยวิธีถามใน `edit-and-review.md` ข้อ 2 ถ้าพี่ถามว่าทำไมถอดเสียงไม่ได้ ตอบสั้น ๆ ว่า "การถอดเสียงอัตโนมัติต้องใช้ Claude แบบที่ทำงานบนคอมพิวเตอร์ครับ ตอนนี้พี่พิมพ์คร่าว ๆ มาได้เลย"
- ห้ามบอกว่าติดตั้งแล้วหรือถอดเสียงแล้ว ถ้าคุณไม่ได้รันคำสั่งและเห็นผลจริง

## 2. ตรวจเครื่อง (ไม่ต้องถามพี่ รันเองได้เลย ไม่มีการติดตั้ง)
รันทีละบรรทัด แล้วจดผลไว้
- เครื่องอะไร: Mac และ Linux ใช้ `uname -sm` · Windows ใช้ `echo %PROCESSOR_ARCHITECTURE%`
- มี uv ไหม: `uv --version`
- มี ffmpeg ไหม: `ffmpeg -version`
- มีตัวถอดเสียงแล้วไหม: `uv tool list` (มองหา `mlx-whisper` หรือ `whisper-ctranslate2`)

เลือกตัวถอดเสียงตามเครื่อง

| เครื่องของพี่ | ตัวถอดเสียง | ต้องมี ffmpeg ไหม |
|---|---|---|
| Mac ชิป Apple (`Darwin arm64`) และมี ffmpeg | `mlx-whisper` (เร็วที่สุดบนเครื่องนี้) | ต้องมี |
| Mac ชิป Apple แต่ไม่มี ffmpeg | `whisper-ctranslate2` | ไม่ต้อง |
| Mac รุ่น Intel (`Darwin x86_64`) | `whisper-ctranslate2` | ไม่ต้อง |
| Windows | `whisper-ctranslate2` | ไม่ต้อง |

ถ้ามีตัวถอดเสียงของเครื่องนั้นอยู่แล้ว ข้ามไปข้อ 5

## 3. ขออนุญาตก่อนติดตั้ง (ถามครั้งเดียว แบบให้กดเลือก)
บอกเป็นภาษาง่าย ไม่ต้องพูดชื่อโปรแกรม เว้นแต่พี่ถาม
> ผมขอติดตั้งตัวช่วยถอดเสียงไว้ในเครื่องพี่ได้ไหมครับ ผมจะได้ฟังคลิปพี่เป็นข้อความเอง พี่ไม่ต้องพิมพ์
> ใช้เน็ตโหลดครั้งแรกราว 1.6 GB ใช้เวลาหลายนาที ทำครั้งเดียว และฟรี
> ก) ติดตั้งเลย (แนะนำ)
> ข) ยังไม่ติดตั้ง พี่พิมพ์เองก่อน
> ง) อื่น ๆ (พิมพ์เอง)

ถ้าพี่ไม่ให้ติดตั้ง ให้ทำงานต่อด้วย `edit-and-review.md` ข้อ 2 และไม่ถามเรื่องนี้ซ้ำในแชตนั้น

สิ่งที่ต้องบอกตามจริงถ้าพี่ถาม
- โปรแกรมที่ติดตั้งเป็นของฟรีแบบเปิดโค้ด: uv (ตัวติดตั้ง) และ Whisper (ตัวถอดเสียง)
- เสียงในคลิปถูกถอดในเครื่องของพี่ ตัวถอดเสียงไม่ส่งไฟล์เสียงไปที่ไหน แต่ข้อความที่ถอดได้จะถูกส่งมาให้คุณอ่านในแชตนี้
- ลบออกได้ทุกเมื่อด้วยข้อ 7

## 4. ติดตั้ง (รันเอง ทีละขั้น ตรวจผลทุกขั้น)
1. ถ้ายังไม่มี uv ให้ติดตั้งจากเว็บทางการของ uv เท่านั้น
   - Mac: `curl -LsSf https://astral.sh/uv/install.sh | sh`
   - Windows: `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`
   - แล้วตรวจด้วย `uv --version` ถ้ายังไม่เจอคำสั่ง ให้เปิดหน้าต่างคำสั่งใหม่ หรือเรียกด้วยที่อยู่เต็ม `~/.local/bin/uv`
2. ติดตั้งตัวถอดเสียงของเครื่องนั้น
   - Mac ชิป Apple ที่มี ffmpeg: `uv tool install --python 3.12 mlx-whisper`
   - เครื่องอื่นทั้งหมด: `uv tool install --python 3.12 whisper-ctranslate2`
3. ตรวจว่าติดตั้งแล้ว: `uv tool list`

ห้ามติดตั้งโปรแกรมอื่นนอกรายการนี้ ห้ามใช้คำสั่งที่ขอรหัสผ่านเครื่อง (เช่น `sudo`) ถ้าขั้นไหนขอรหัสผ่านหรือขึ้นข้อความผิดพลาดที่แก้ไม่ได้ใน 2 ครั้ง ให้หยุด บอกพี่ตามจริงว่าติดตรงไหน แล้วทำงานต่อด้วยวิธีพิมพ์

## 5. ถอดเสียงคลิปของพี่
ให้พี่บอกว่าคลิปอยู่โฟลเดอร์ไหน หรือให้พี่ลากไฟล์มาใส่ ใช้ได้ทั้งไฟล์วิดีโอและไฟล์เสียง เก็บผลไว้ในโฟลเดอร์ `ถอดเสียง` ข้างไฟล์คลิป ห้ามแก้หรือลบไฟล์คลิปต้นฉบับ

- `mlx-whisper`:
  `mlx_whisper "<ไฟล์คลิป>" --model mlx-community/whisper-large-v3-turbo --language th --word-timestamps True --output-format json --output-dir "<โฟลเดอร์ถอดเสียง>"`
- `whisper-ctranslate2`:
  `whisper-ctranslate2 "<ไฟล์คลิป>" --model large-v3-turbo --language th --word_timestamps True --output_format json --output_dir "<โฟลเดอร์ถอดเสียง>" --compute_type int8`

ครั้งแรกจะโหลดตัวถอดเสียง บอกพี่ก่อนว่า "ครั้งแรกรอหลายนาทีนะครับ ครั้งต่อไปเร็วขึ้น" คลิป 1 นาทีใช้เวลาตั้งแต่ไม่ถึงนาทีถึงหลายนาที แล้วแต่เครื่อง

ผลที่ได้คือไฟล์ `.json` มีข้อความทีละช่วง พร้อมวินาทีเริ่มและจบ ให้เปิดอ่านเอง

## 6. ใช้ข้อความที่ถอดได้อย่างไร
ตัวถอดเสียงฟังผิดได้ โดยเฉพาะชื่อสินค้า ชื่อคน ตัวเลข และคำแรกของคลิป ให้ทำตามนี้ทุกครั้ง
1. ส่งข้อความที่ถอดได้ให้พี่อ่าน เป็นข้อความธรรมดา สั้น ๆ ทีละช่วง แล้วถามข้อเดียวว่า "ตรงกับที่พี่พูดไหมครับ" ให้พี่แก้เฉพาะคำที่ผิด
2. สะกดชื่อสินค้าตาม `products.md` เสมอ ถึงตัวถอดเสียงจะเขียนมาอีกแบบ
3. ห้ามเติมคำที่พี่ไม่ได้พูด ห้ามตัดคำจนความหมายเปลี่ยน ช่วงที่ฟังไม่ชัดให้ใส่ `[ฟังไม่ชัด]` แล้วถามพี่
4. ตรวจคำเสี่ยงของสิ่งที่พี่พูดจริงตาม `claims.md` ถ้าพี่พูดคำที่ใช้ไม่ได้ ให้บอกพี่ และเสนอให้ตัดประโยคนั้นออกจากคลิป ห้ามแก้คำในข้อความตามเสียงพูดให้ต่างจากที่พี่พูด
5. ทำ "ลำดับตัด" ตาม `edit-and-review.md` ข้อ 3 โดยใส่วินาทีเริ่มและจบของแต่ละประโยคที่เลือก เช่น `0:12–0:19` และบอกพี่ว่าวินาทีจากตัวถอดเสียงคลาดได้ราวครึ่งวินาที ให้พี่ขยับจุดตัดตามหูตอนกดตัด
6. ข้อความตามเสียงพูด (ซับ) ให้ใช้ฉบับที่พี่ยืนยันแล้วเท่านั้น

เมื่อถอดเสียงสำเร็จครั้งแรก ให้ร่วมยินดี 1 บรรทัด และเพิ่มบรรทัดนี้ใน "การ์ดของพี่": `เครื่องพร้อม: ถอดเสียงได้`

## 7. ถ้าพี่อยากลบออก
- `uv tool uninstall mlx-whisper` หรือ `uv tool uninstall whisper-ctranslate2`
- ตัวถอดเสียงที่โหลดไว้อยู่ในโฟลเดอร์ `.cache/huggingface` ในโฟลเดอร์ผู้ใช้ ลบได้ ถามพี่ก่อนลบทุกครั้ง

## 8. เสียงประกอบและการตรวจเสียง (ยังไม่ต้องติดตั้ง)
มีเครื่องมือเปิดโค้ดชื่อ earshot (https://github.com/Leonxlnx/earshot) ที่สร้างเสียงประกอบสั้น ๆ และวัดความดังของเสียงได้ แต่**ถอดคำพูดไม่ได้** ทีมจะใช้คู่กับสกิลตัดคลิปเมื่อเปิดใช้ ตอนนี้ยังไม่ต้องติดตั้งให้ผู้ใช้ และห้ามบอกว่ามันถอดเสียงได้
